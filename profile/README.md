## Det digitale værksted

Her bygger og driver vi de systemer, der forbinder kunderne med det praktiske arbejde på værkstedet:

| Område | Formål |
| --- | --- |
| **Offentlig hjemmeside** | Ydelser, værkstedsinformation og tydelige forventninger |
| **Kundeportal** | Bookinger, rapporter, priser, beskeder og servicehistorik |
| **Værkstedsdrift** | Sikker og effektiv administration af kunde- og serviceforløb |
| **Tide** | Automatiseret kvalitet, sikkerhed, afhængigheder og leverancer |

Vores primære kodebase er privat. Fejl, idéer og teknisk arbejde samles i den fælles [Product backlog](https://github.com/orgs/dykkervaerkstedet/projects/1), hvor AI-agenter og Tidebot kan oprette strukturerede emner til menneskelig vurdering.

## Sikkerhed

Del aldrig legitimationsoplysninger, kundedata eller sårbarheder i offentlige issues. Sikkerhedsproblemer rapporteres privat til organisationens vedligeholdere.
